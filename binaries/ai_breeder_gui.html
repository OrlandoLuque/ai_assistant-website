prompt-breeder, gui-pro

Purpose

egui desktop dashboard for inspecting PromptBreeder runs, the visual companion to the ai_breeder CLI. Read-only: it renders a run's checkpoints, population, lineage, and ledger without ever mutating them.

Build

cargo build --release --bin ai_breeder_gui --features "prompt-breeder,gui-pro"

The six tabs

  • Overview — config hash, ledger tip, fitness summary.
  • Population — per-unit table with operator, fitness, parents, and a task-prompt preview.
  • Lineage — DAG sizing + operator histogram.
  • Ledger — chain integrity view.
  • Events — the most recent 500 raw events.
  • Fitness — best-per-generation + diversity timeline extracted from the ledger.

Shared auditor contract

Like every auditable subsystem (ai_feedback, ai_prompt_synth, ai_breeder), the underlying ledger is an append-only JSONL with a Blake3 prev_hash → this_hash chain, optional Ed25519 signatures via the DispatchSigner trait, and a global freeze switch honoured by every learner. One mental model audits all three.
