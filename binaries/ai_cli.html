full,diagnostic-logging

Purpose

Non-interactive command-line driver for scripting, CI/CD, and one-shot queries. Exposes the full library surface (providers, RAG, tools, cost, anti-hallucination, research, quality gates) as discrete subcommands.

Build

cargo build --release --bin ai_cli --features "full,diagnostic-logging"

Subcommands

scan, providers, models, config, butler, query, bench, test, cost (V77), verify (V88), research (V88, needs research), quality (V88), help. query and verify accept --image <path|URL> when built with feature vision (V90.18).

Usage

# Provider detection + one-shot query
ai_cli scan
ai_cli query -p "Hello" -P ollama
ai_cli models -P ollama
ai_cli config

# Verbose diagnostics (feature diagnostic-logging)
ai_cli -v   scan        # info
ai_cli -vv  scan        # debug
ai_cli -vvv scan        # trace
ai_cli --log-file diag.log scan

# V77 cost
ai_cli cost report  --snapshot cost.json
ai_cli cost export  --snapshot cost.json --output cost.csv --force

# V88 verify (anti-hallucination)
ai_cli verify "Is water wet?" --strategy mark --faithfulness --cove --quality-gates

# V88 research (needs feature "research")
ai_cli research "transformer attention" --providers arxiv,scholar --bibtex --review

# V90.18 vision (needs feature "vision")
ai_cli query --image diagram.png "Explain this architecture"
ai_cli query -P ollama --model llava --image photo.jpg --image notes.png "Compare these"
ai_cli verify --image chart.png --faithfulness --quality-gates "Summarize the trend"
