src/bin/ai_breeder.rs
required-features
prompt-breeder

Purpose

Read-only auditor for PromptBreeder evolutionary prompt-optimization runs. Inspect run checkpoints and their populations, verify and pretty-print the tamper-evident ledger of mutations, export a population to JSON, and compare two runs. Never mutates any artifact — safe to point at a live run directory.

Build

cargo build --release --bin ai_breeder --features prompt-breeder

Usage

ai_breeder list-runs         <DIR>
ai_breeder show-run          <CKPT_FILE>
ai_breeder ledger-verify     <LEDGER_JSONL>
ai_breeder ledger-show       <LEDGER_JSONL> [--last N]
ai_breeder export-population <CKPT_FILE> <OUT_JSON>
ai_breeder compare-runs      <CKPT_A> <CKPT_B>

Defenses

  • Strictly read-only: opens checkpoints and ledgers for inspection, never writes back.
  • Ledger integrity: ledger-verify walks the append-only JSONL hash chain and exits non-zero on any break.
  • Bounded output: ledger-show --last N caps how much of a long ledger is rendered.
  • Export goes to an explicit output path you name — no in-place modification of the run.
