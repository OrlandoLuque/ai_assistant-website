ai_acp_auditACP SLO auditor CLI

Group
Editor integration (Phase A.2, V107)
Binary path
src/bin/ai_acp_audit.rs
required-features
acp

Purpose

Read-only auditor for SLO log files emitted by ai_acp serve. Reads JSONL records (one per handshake / prompt / first_chunk event), checks them against the SLO targets, and either prints a summary or exits non-zero if --strict is passed.

Build

cargo build --release --bin ai_acp_audit --features acp

Verbs

ai_acp_audit list   [--dir D]
ai_acp_audit show   <FILE>
ai_acp_audit audit  [--dir D] [--strict]

Default --dir: ./.ai_assistant/acp_logs. --strict makes audit exit 1 on any breach — drops directly into CI as a regression gate.

SLO targets

  • Handshake ≤ 200 ms
  • First chunk ≤ 1000 ms
  • Sustained throughput ≥ 30 chunks/s

Example

$ ai_acp_audit list
FILE                                              RECORDS   SESSIONS
acp_1777806862_71464.jsonl                              2          1

$ ai_acp_audit audit --strict
ACP audit (.ai_assistant/acp_logs)
  Files:                     1
  Records:                   2
  Handshakes:                1 (breach >200ms: 0)
  Prompts:                   1 (breach <30 chunks/s: 0)
  First-chunk records:       0 (breach >1000ms: 0)
OK: all records within SLO targets
