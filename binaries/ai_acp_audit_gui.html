ai_acp_audit_guiACP SLO auditor (egui desktop)

Group
Editor integration (Phase A.2, V107)
Binary path
src/bin/ai_acp_audit_gui.rs
required-features
gui-acp (= acp + dep:eframe)

Purpose

Visual read-only auditor for ACP SLO log files. Pairs with ai_acp_audit. Shows: list panel of discovered .jsonl log files, per-file records table with red-coded SLO breaches, summary panel showing handshake / prompt / first-chunk breach counts, status badge (OK / BREACH).

Build

cargo build --release --bin ai_acp_audit_gui --features gui-acp

Run

cargo run --release --bin ai_acp_audit_gui --features gui-acp

Default directory: ./.ai_assistant/acp_logs. Change in the toolbar and click Reload.

Why a separate gui-acp feature?

The auditor only needs eframe + the acp module — it does not pull in the rest of the desktop stack (graph viz, file dialogs, RAG, butler) that gui-pro brings. Users who want only the ACP auditor pay only for that.
