Not a user-facing tool. This binary exists only to back integration tests of embedded_server and the ai_proxy streaming path. It is never shipped or run by end users — it's listed here for completeness so every binary in the crate has a reference page.

Purpose

A tiny hand-rolled HTTP server (std::net::TcpListener, no async runtime, no extra deps) that impersonates an external llama-server so the test suite can exercise the proxy, the embedded-server launcher, and the V150 SSE streaming passthrough without a real model.

Build

cargo build --bin mock_llama_server --features vision

Routes

GET  /health                                  200 after an optional MOCK_LLAMA_DELAY_MS ramp
GET  /v1/models                               single dummy model entry
GET  /sse-test?chunks=N&gap_ms=M&stall_after=K  text/event-stream with N chunks, M ms apart;
                                              stall_after=K emits K chunks then hangs (drives
                                              the per-chunk-timeout test)
POST /v1/chat/completions                     SSE when the body contains "stream":true, else
                                              a single JSON chat response
GET  /__shutdown                              graceful exit

Env knobs

  • MOCK_LLAMA_DELAY_MS — ramp-up before /health returns 200 (simulates slow boot).
  • MOCK_SSE_CHUNKS / MOCK_SSE_GAP_MS — default chunk count and inter-chunk gap for the SSE endpoints.
  • MOCK_SSE_STALL_AFTER — emit this many chunks then hang forever (per-chunk-timeout coverage).
