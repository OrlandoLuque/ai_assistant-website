ai_local_inferLocal inference runner + benchmark

Group
Local inference
Binary path
src/bin/ai_local_infer.rs
required-features
local-inference

Purpose

Drive the in-crate local-inference backends directly: probe backend availability and VRAM, stream a single prompt while persisting an SLO record, or repeat a generation N times to print a throughput/latency summary. Pluggable backend (stub for tests, candle, llama-cpp).

Build

cargo build --release --bin ai_local_infer --features local-inference

Usage

ai_local_infer info                           # backend availability + VRAM detection
ai_local_infer generate [opts]                # stream one prompt; persist SLO record
ai_local_infer bench    [opts] [--iters N]    # repeat generate N times; print summary

# Common options for generate / bench:
#   --backend <stub|candle|llama-cpp>   (default: stub)
#   --model   <path>                    (required for non-stub backends)
#   --prompt  <text>                    (default: 'Hello, world.')
#   --max-tokens <N>                    (default: 256)
#   --temperature <T>  --top-p <T>

Notes

  • Every generate writes an SLO record to ./.ai_assistant/local_infer_logs — audit it with ai_local_infer_audit.
  • The stub backend needs no model file and is used by the test harness.
