ai_local_infer_auditLocal-inference SLO log auditor (read-only)

Group
Local inference
Binary path
src/bin/ai_local_infer_audit.rs
required-features
local-inference

Purpose

Read-only auditor for the SLO records that ai_local_infer persists on every generation. List logs with a per-file summary, pretty-print one file's records, or run an aggregate audit that exits non-zero on a breach — usable as a CI gate.

Build

cargo build --release --bin ai_local_infer_audit --features local-inference

Usage

ai_local_infer_audit list   [--dir D]            # list logs with per-file summary
ai_local_infer_audit show   <FILE>              # pretty-print a log file's records
ai_local_infer_audit audit  [--dir D] [--strict]  # aggregate audit; non-zero on breach

# Default --dir: ./.ai_assistant/local_infer_logs

Defenses

  • Strictly read-only — never writes to the log directory.
  • --strict turns warnings into a non-zero exit so the audit can gate CI.
