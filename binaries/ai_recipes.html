Workflows (Phase A.1, V106)
Binary path
src/bin/ai_recipes.rs
required-features
(none — recipes module always compiled)

Purpose

Read-only auditor for declarative YAML recipes (apiVersion recipes/v1) discovered under ./.ai_assistant/recipes/ or a chosen directory. Inspect metadata + variables + steps, validate against the schema, render the sub-recipe call graph, or run an aggregate audit that exits non-zero on issues.

Build

cargo build --release --bin ai_recipes

Usage

ai_recipes list [--dir <PATH>]
ai_recipes inspect <FILE|NAME> [--dir <PATH>]
ai_recipes validate <FILE|NAME> [--dir <PATH>]
ai_recipes graph [--dir <PATH>]
ai_recipes audit [--dir <PATH>]

Defenses

  • File size cap 256 KiB, symlinks rejected, UTF-8 only.
  • Sub-recipe depth ≤ 8 (prevents recursion).
  • Steps per recipe ≤ 64.
  • shell step type rejected unless caller opts in.
  • Subset-YAML parser: anchors, references, tags, and flow mappings {...} all rejected.
